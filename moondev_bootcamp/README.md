## 💡 How to Add New Projects
* When starting a new day's project in the bootcamp, create a folder inside `bootcamp_projects/` (e.g., `bootcamp_projects/day_01_crypto_bot`).
* When building your own side projects, create a folder inside `my_projects/` (e.g., `my_projects/solana_trading_dashboard`).
