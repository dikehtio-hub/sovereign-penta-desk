SHARED OBSIDIAN VAULT (link HyperLiquid + Polymarket into ONE vault)
--------------------------------------------------------------------------------
Obsidian [[wikilinks]] only resolve inside a SINGLE vault. Point both suites at
the same folder and their notes cross-link; leave it unset and each keeps its own
private vault (cross-links are then hidden, never broken).

# PowerShell - set once per terminal:
$env:OBSIDIAN_VAULT_PATH = "C:\Users\ixis1\Desktop\DEV\obsidian_vault"

# Then export both suites into it:
python HyperLiquid/main.py obsidian --once
python Polymarket/Polymarket_Monarch/obsidian_sync.py --once

# Open that folder in Obsidian ("Open folder as vault"). You get:
#   Monarch_Hub.md           <- index note linking both suites
#   HyperLiquid_Monarch.md   + Whales/0x....md   (perp whales)
#   Polymarket_Monarch.md    + Wallets/0x....md  (sharp traders)
# Run either exporter with --watch to keep the vault live.

6. OPERATIONAL RUNTIME MODES & RATE LIMITING
--------------------------------------------------------------------------------

💡 Hyperliquid enforces a budget of 1,200 weight/min per IP address.

• Mode A — Interactive Desktop Dashboard:
    Run: python main.py dashboard
    (The dashboard embeds an internal collector automatically. No need to run
    a separate collector in another window).

• Mode B — Dedicated 24/7 Headless Server:
    Run: python main.py collector
    (Runs continuous ingestion; inspect on-demand using 'python main.py dashboard --once'
    or 'python main.py summary').

⚠️  Caution: Do NOT run 'python main.py collector' and 'python main.py dashboard'
    simultaneously in two separate terminals on the same IP, as two concurrent
    collectors will spend ~1,800 weight/min and exceed the 1,200 weight/min ceiling.
